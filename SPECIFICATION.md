# איפיון אפליקציית ספריית הקודש

## סקירה כללית

אפליקציית דסקטופ (Avalonia + .NET) להצגת, חיפוש ולימוד ספרי קודש:
- **כתבי הרב קוק** - ייבוא מקבצי Word מקומיים
- **תנ"ך עם פרשנים** - רש"י, מצודות, אבן עזרא ועוד (מספריא)
- **תלמוד בבלי** - עם רש"י ותוספות (מספריא)
- **בניית דפי מקורות** - לשיעורים ולימוד עצמי

**פלטפורמות:** Windows, Linux, macOS, Android (משני)
**טכנולוגיה:** Avalonia UI + .NET 8 + Lucene.NET + SQLite + Sefaria API

## Sefaria API - אינטגרציה

### API Endpoints

```
Base URL: https://www.sefaria.org/api

GET /texts/{ref}           - קבלת טקסט
GET /texts/{ref}?commentary=1  - טקסט + פרשנים
GET /links/{ref}           - קישורים לטקסט
GET /index                 - רשימת כל הספרים
GET /search               - חיפוש
```

### דוגמאות קריאות

```csharp
// קבלת פסוק עם פרשנים
GET /api/texts/Genesis.1.1?commentary=1

// קבלת דף גמרא
GET /api/texts/Berakhot.2a

// חיפוש
GET /api/search?q=בראשית&filters=Tanakh
```

### אסטרטגיית שמירה (Caching)

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│   Sefaria   │ ───▶ │ Local Cache │ ───▶ │   SQLite    │
│    API      │      │  (Memory)   │      │  (Persist)  │
└─────────────┘      └─────────────┘      └─────────────┘
                            │
                     TTL: 24 hours
                     Max: 500MB
```

**מדיניות Cache:**
- טקסטים בסיסיים (תנ"ך, גמרא) - שמירה לצמיתות
- פרשנים - שמירה לצמיתות
- תוצאות חיפוש - TTL 1 שעה
- Offline mode - כל מה ש-cached זמין

### טבלת Cache

```sql
CREATE TABLE sefaria_cache (
    ref             TEXT PRIMARY KEY,     -- "Genesis.1.1"
    content_json    TEXT NOT NULL,        -- Response מלא
    fetched_at      DATETIME,
    expires_at      DATETIME,             -- NULL = לעולם
    content_type    TEXT                  -- 'text'/'commentary'/'link'
);
```

### טבלאות Database לדפי מקורות

```sql
-- דפי מקורות
CREATE TABLE source_sheets (
    id              INTEGER PRIMARY KEY,
    title           TEXT NOT NULL,
    description     TEXT,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME,
    is_template     BOOLEAN DEFAULT FALSE,  -- תבנית לשימוש חוזר
    folder_id       INTEGER REFERENCES sheet_folders(id)
);

-- תיקיות לדפי מקורות
CREATE TABLE sheet_folders (
    id              INTEGER PRIMARY KEY,
    name            TEXT NOT NULL,
    parent_id       INTEGER REFERENCES sheet_folders(id),
    sort_order      INTEGER
);

-- פריטים בדף מקורות
CREATE TABLE sheet_items (
    id              INTEGER PRIMARY KEY,
    sheet_id        INTEGER REFERENCES source_sheets(id),
    item_type       TEXT NOT NULL,          -- 'source'/'text'/'heading'/'divider'/'image'
    sort_order      INTEGER NOT NULL,

    -- עבור מקורות
    source_ref      TEXT,                   -- "Genesis.1.1" או content_id
    source_type     TEXT,                   -- 'sefaria'/'local'/'bookmark'
    source_text     TEXT,                   -- הטקסט (cached)

    -- עבור טקסט חופשי/כותרת
    custom_text     TEXT,

    -- הערות
    note            TEXT,

    -- עיצוב
    style_json      TEXT                    -- {"fontSize": 14, "bold": true}
);

-- תגיות לדפי מקורות
CREATE TABLE sheet_tags (
    id              INTEGER PRIMARY KEY,
    sheet_id        INTEGER REFERENCES source_sheets(id),
    tag             TEXT NOT NULL
);

CREATE INDEX idx_sheet_tags ON sheet_tags(tag);
```

### קוד ייצוא PDF (דוגמה)

```csharp
public class PdfExporter
{
    public void ExportSourceSheet(SourceSheet sheet, string outputPath)
    {
        Document.Create(container =>
        {
            container.Page(page =>
            {
                page.Size(PageSizes.A4);
                page.Margin(2, Unit.Centimetre);
                page.ContentFromRightToLeft();  // RTL לעברית!

                page.Header().Text(sheet.Title)
                    .FontSize(24).Bold().AlignCenter();

                page.Content().Column(col =>
                {
                    foreach (var item in sheet.Items)
                    {
                        col.Item().Component(new SourceItemComponent(item));
                    }
                });

                page.Footer().AlignCenter()
                    .Text(x => x.CurrentPageNumber());
            });
        }).GeneratePdf(outputPath);
    }
}
```

### ייצוא Word

```csharp
public class WordExporter
{
    public void ExportSourceSheet(SourceSheet sheet, string outputPath)
    {
        using var doc = WordprocessingDocument.Create(outputPath, WordprocessingDocumentType.Document);

        var mainPart = doc.AddMainDocumentPart();
        mainPart.Document = new Document();
        var body = mainPart.Document.AppendChild(new Body());

        // RTL Settings
        var sectionProps = new SectionProperties(
            new BiDi()  // Right-to-Left
        );

        // Title
        body.AppendChild(CreateHeading(sheet.Title, 1));

        // Items
        foreach (var item in sheet.Items)
        {
            body.AppendChild(CreateSourceParagraph(item));
        }

        body.AppendChild(sectionProps);
    }
}
```

## נספח: מודול ייבוא מ-Word

### אתגרי הייבוא

| מצב | תיאור | פתרון |
|-----|-------|-------|
| **קבצים עם Styles** | יש Heading 1/2/3 מוגדרים | ייבוא אוטומטי לפי סגנונות |
| **קבצים ללא Styles** | רק טקסט רגיל | זיהוי אוטומטי + אישור ידני |
| **קבצים מעורבים** | חלק עם סגנונות, חלק בלי | משולב |

### מצב 1: ייבוא לפי Styles

```
Word Style          →  מבנה באפליקציה
─────────────────────────────────────
Heading 1           →  ספר (Book)
Heading 2           →  פרק (Chapter)
Heading 3           →  סעיף (Section)
Heading 4           →  תת-סעיף (SubSection)
Normal              →  תוכן (Content)
```

### מצב 2: זיהוי אוטומטי (Heuristics)

כללי זיהוי לפרקים וסעיפים:

```
זיהוי כותרת פרק:
─────────────────
✓ "פרק [א-ת]" / "פרק [0-9]+"
✓ "חלק [א-ת]" / "חלק ראשון"
✓ "שער [א-ת]"
✓ "מאמר [א-ת]"
✓ שורה קצרה (<50 תווים) + שורה ריקה אחריה
✓ טקסט מודגש (Bold) בשורה נפרדת

זיהוי כותרת סעיף:
──────────────────
✓ "[א-ת]." בתחילת פסקה (א. ב. ג.)
✓ "[0-9]+." בתחילת פסקה (1. 2. 3.)
✓ "סעיף [א-ת]"
✓ "אות [א-ת]"
✓ פסקה קצרה מודגשת

זיהוי הפניות:
─────────────
✓ (שם ספר פרק:פסוק) - תנ"ך
✓ (מסכת דף.) - גמרא
✓ "עיין..." / "ראה..."
```

- [ ] אין תווים לא תקינים
- [ ] קידוד UTF-8 תקין
