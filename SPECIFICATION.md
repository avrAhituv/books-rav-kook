# איפיון אפליקציית כתבי הרב קוק

## סקירה כללית

אפליקציית דסקטופ (Avalonia + .NET) להצגת, חיפוש ולימוד כתבי הרב אברהם יצחק הכהן קוק זצ"ל.

**פלטפורמות:** Windows, Linux, macOS, Android (משני)
**טכנולוגיה:** Avalonia UI + .NET 8 + Lucene.NET + SQLite

### טבלאות קישורים וחיבורים

```
┌─────────────────────────────────────────────────────────────┐
│                    TEXT_LINKS                                │
├─────────────────────────────────────────────────────────────┤
│ id              INTEGER PRIMARY KEY                          │
│ source_id       INTEGER REFERENCES content(id)               │
│ target_id       INTEGER REFERENCES content(id)               │

│ similarity      REAL                    -- 0-1 דמיון        │
│ description     TEXT                    -- תיאור הקשר       │
│ is_manual       BOOLEAN                 -- ידני/אוטומטי     │
│ created_by      TEXT                    -- 'system'/'user'  │

-- סוגי קישורים (link_type):
-- 'similar'      - טקסטים דומים בתוכן
-- 'reference'    - הפניה מפורשת
-- 'continuation' - המשך של אותו רעיון
-- 'contrast'     - רעיון מנוגד/משלים
-- 'source'       - מקור שהרב מצטט
-- 'parallel'     - מקבילה בספר אחר

┌─────────────────────────────────────────────────────────────┐
│                    EXTERNAL_REFS                             │
├─────────────────────────────────────────────────────────────┤
│ id              INTEGER PRIMARY KEY                          │
│ content_id      INTEGER REFERENCES content(id)               │
│ ref_type        TEXT                    -- 'tanach'/'talmud' │
│ ref_book        TEXT                    -- 'בראשית'/'ברכות' │
│ ref_location    TEXT                    -- 'א,א' / 'דף ב.'  │
```
